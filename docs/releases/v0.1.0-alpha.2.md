# logi-rex 0.1.0-alpha.2 — public npm preview

The first public npmjs.org release of the OpenLogi-focused alpha. This release changes distribution and setup documentation, not the action bridge or native mappings.

## Changes

- Publish `@aruniverse/logi-rex` publicly on npmjs.org under `next`, with GitHub Actions build provenance.
- Retain the same CLI/export `.tgz` and `SHA256SUMS` on GitHub Releases.
- Prepare tokenless trusted publishing; a temporary npm token bootstraps the first package publication.
- Keep prereleases off `latest` and GitHub Latest, with regression checks for public access, registry selection, provenance, and channel guards.

## Install

Node.js 22+ and pnpm are required. No registry login is needed:

```sh
pnpm add --global @aruniverse/logi-rex@next
logi-rex doctor
```

For this exact version, install `@aruniverse/logi-rex@0.1.0-alpha.2`. If an existing `.npmrc` routes `@aruniverse` to GitHub Packages, change that scope mapping to `https://registry.npmjs.org` first.

Install Rex and OpenLogi separately. Export a paired setup using the exact persisted device key from your OpenLogi config, review the generated files, and back up your configs before merging. See the [setup guide](https://github.com/aruniverse/logi-rex/tree/v0.1.0-alpha.2#connect-openlogi). Installation and export do not modify live configurations or start a daemon.

## Verification and limitations

Automated gates cover unit/regression tests, minified builds, archive validation, SDK protocol simulation, and a clean installed-CLI/export smoke check.

The existing [three-button observation](https://github.com/aruniverse/logi-rex/blob/v0.1.0-alpha.2/docs/openlogi-smoke.md) remains scoped to its earlier source build: MX Master 3S over Bluetooth, OpenLogi 0.8.18, and Rex build 1541. It is not a new hardware test of this release or verification of full presets, wheels, gestures, MX Master 4, or MX Keys.

CLI bridge dispatch and real Logi Options+ host acceptance remain experimental. The unverified `.lplug4` installer is not attached to this release.
