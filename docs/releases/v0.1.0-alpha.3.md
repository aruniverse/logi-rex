# logi-rex 0.1.0-alpha.3 — trusted publishing preview

An OpenLogi-focused preview to verify npm trusted publishing after removing the repository's bootstrap `NPM_TOKEN` secret. Device mappings and action behavior are unchanged.

## Release changes

- Publish through GitHub Actions OIDC, without a stored npm publishing token.
- Wait for public registry visibility and verify the actual release channel after publishing.
- Provide a verification-only workflow dispatch that does not republish a version.
- Retain the verified CLI/export archive and checksum on GitHub Releases. No unverified Options+ installer is attached.

## Install

With Node.js 22+ and pnpm:

```sh
pnpm add --global @aruniverse/logi-rex@next
logi-rex doctor
```

To pin this version, use `@aruniverse/logi-rex@0.1.0-alpha.3`. Public installation requires no registry login. Remove or change any old `.npmrc` scope mapping that routes `@aruniverse` to GitHub Packages before using npmjs.org.

Installation does not configure your devices. Follow the [OpenLogi setup guide](https://github.com/aruniverse/logi-rex/tree/v0.1.0-alpha.3#connect-openlogi), use your exact persisted device key, review the exported files, and back up your live configs before merging them.

## Limitations

The earlier [three-button observation](https://github.com/aruniverse/logi-rex/blob/v0.1.0-alpha.3/docs/openlogi-smoke.md) does not constitute a new hardware test of this release. Full presets, other device templates, and real Options+ host acceptance remain outside that observation. The CLI bridge and SDK host path remain experimental.

The npm bootstrap assigned `latest` to `0.1.0-alpha.2`; correcting that alias is a separate registry-permission check. Use `@next` or this exact version rather than treating a bare package-name install as stable. GitHub releases in this preview line remain prereleases, not GitHub Latest.
