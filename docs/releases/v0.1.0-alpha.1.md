# logi-rex 0.1.0-alpha.1 — OpenLogi preview

An experimental OpenLogi-focused release for connecting native mouse/key mappings to Rex. This release publishes the CLI/export package and its checksum; it does **not** publish the unverified Logi Options+ `.lplug4` installer.

## Included

- Paired export of Rex Lua bindings, OpenLogi TOML, and a readable control map.
- Tabs, Panes, and Sessions starter presets for the included device templates.
- Read-only Rex diagnostics, with structured JSON output and nonzero failure status.
- CLI action-bridge code, with foreground and destructive-action safeguards.
- Automated package, config-generation, SDK-simulation, and artifact-installation checks.

## Manual smoke evidence

A local three-button subset worked with MX Master 3S over Bluetooth, OpenLogi 0.8.18, Rex 0.1.0 build 1541, and macOS 27.0.1: Back/Forward changed tabs, and Middle Click zoomed/restored a pane. See the [scoped observation](https://github.com/aruniverse/logi-rex/blob/v0.1.0-alpha.1/docs/openlogi-smoke.md) for what was and was not checked. This is not a full-preset or hardware-support guarantee.

## Install

Download the attached `.tgz`, then install that exact file:

```sh
pnpm add --global ./aruniverse-logi-rex-0.1.0-alpha.1.tgz
logi-rex doctor
logi-rex export --model mx-master-3s --device 'unit:YOUR_ACTUAL_DEVICE_ID' --preset tabs --out ./logi-rex-setup
```

Use the real persisted device key from your OpenLogi config; it may have a different prefix than the placeholder. Choose a new output directory outside public version control. Review the generated README, back up configs, merge both fragments, and reload Rex with `rex config reload`. Export does not modify live configuration.

The registry prerelease dist-tag is `next`, not `latest`. The attached archive can be downloaded without GitHub Packages registry credentials once the repository is public.

## Known limitations

- Native mappings depend on the input manager exposing the named controls; device/firmware support belongs upstream.
- Full presets, wheel/gesture mappings, MX Master 4, MX Keys, and reconnect behavior have not been manually verified here.
- CLI bridge dispatch has automated coverage but was not part of the manual three-button check.
- Logi Options+ SDK code remains experimental in the source/package. Real host loading and prerelease manifest acceptance are unverified, so no installer is attached.
- Optional device-wide gestures can send reserved chords outside Rex; leave them disabled for a first check.
